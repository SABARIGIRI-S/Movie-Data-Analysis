Movie Data Analysis using Pandas, NumPy, Seaborn & Matplotlib

Project Overview
This project analyzes a dataset of movies using Python data analysis libraries.  
It explores relationships between budget, revenue, scores, and other attributes — providing insights into what makes a movie successful.

Tools & Libraries Used
Python 3
pandas – Data cleaning and manipulation  
numpy – Statistical computations  
matplotlib – Basic plotting  
seaborn – Advanced data visualization  

Dataset
The dataset used in this project (`movies.csv`) contains information about movies such as:
- Name  
- Genre  
- Year  
- Rating  
- Budget  
- Gross Revenue  
- Score  
- Director, Writer, and Star  

Data Cleaning Steps
1. Handled missing values  
2. Removed duplicates  
3. Converted data types where necessary  
4. Filled missing numeric and categorical values appropriately  

Exploratory Data Analysis (EDA)
- Genre-based gross and rating comparisons  
- Correlation between budget, gross, votes, and score  
- Visualization of key trends using heatmaps, histograms, and scatter plots  

Statistical Insights
Used NumPy for:
- Mean, Median, and Standard Deviation  
- Numeric summaries for budget, gross, and scores  

Visualizations
- Distribution of movie scores  
- Gross vs Budget scatterplot  
- Top 10 Companies by Average Gross Revenue  
- Correlation Heatmap of numeric columns
